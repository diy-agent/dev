## 遗留建议

### 1. diy-dev skill 的 `packages/` vs `pkgs/` 不一致

diy-dev skill 规定"子包目录用 `packages/` 不用 `pkgs/`"，但 diy 实际使用 `pkgs/`、diy-research 使用 `pkgs/` 和 `pkgs.ts/`。skill 规定与实际项目不一致，需二选一统一。

### 2. _diy 自身缺少约束声明

`_diy/AGENTS.md` 没有引用根文件的硬约束（如禁止裸 pip、禁止缺省分支 push）。因为 `_diy` 是工具项目，agent 在 `_diy` 下操作时可能不会接触到上级 `~/git/AGENTS.md`（取决于 cwd）。建议在 `_diy/AGENTS.md` 中简要引用根约束，或直接复制关键硬约束。

### 3. _diy-45 worktree

由 `dev start` 正常创建，AGENTS.md 副本是预期行为。完成对应 issue 后 `dev remove` 即可清理。

### 4. diyq/AGENTS.md 可后续充实

当前 9 行，仅包含项目定位和 Python 版本。可参照 `diy/AGENTS.md` 的结构补充目录结构、sha.sh 命令、子模块说明。
