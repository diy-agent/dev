# 架构检查表

自动化代码检查的规则清单。每条对应一条可机器验证的检查项。

---

## 日期规范

- [ ] 时区统一使用机器本地时区（如 +0800），不强制 UTC
- [ ] ISO 8601 格式：`%Y-%m-%dT%H:%M:%S+0800`（带时区偏移）
- [ ] 短格式：`%H:%M:%S`（日志时间戳）
- [ ] 使用 `datetime.now()` 取本地时间，不做 timezone 转换

## 日志规范

- [ ] 使用标准 `logging` 模块，不自制日志系统
- [ ] logger 命名层级：`diy.app.*`（GUI 进程）/ `agentd`（daemon 进程）
- [ ] 消息前缀 `[category]` 标注来源（watcher / probe / timer / health / main / panel）
- [ ] 三路一致：文件（JSONL ~/.diy/app.log）+ stderr + GUI LogPanel
- [ ] 禁止 `except ...: pass` — 至少 `logger.error()` 到 stderr
- [ ] 文件端 JSONL 字段：`t` / `l` / `n` / `c` / `m`
- [ ] `-vv` 展示异常堆栈
